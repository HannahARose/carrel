Carrel can now file your documents. Point it at files or a folder such as Downloads, and it reads each item, drafts its catalog card with a model running on your computer, proposes a collection and a sensitivity, and waits for you to approve. Nothing leaves your computer. This is a 0.x release, so anything may change before 1.0; the Mac app follows in v0.5.

New here? Start with [Getting started](https://github.com/HannahARose/carrel/wiki/Getting-Started).

## Filing documents

- **`carrel ingest PATH...`** adds files and folders to a queue, and a background worker drafts them one at a time. `--wait` drafts in the foreground with a full report, `--dry-run` shows what would be added without running a model, and `--status` shows the queue. A worker that stops (a crash, a restart) carries on where it was next time.
- **Each item gets** its text read (PDF text, OCR for scans, plain text and project files for code bundles), a drafted card (title, summary, date, tags), a collection chosen by your routing rules or a model, and a sensitivity rating. Account and identity numbers mark an item restricted, and a card that would repeat one is held for you.
- **Duplicates:** exact copies are caught by checksum. Likely duplicates (the same file name, a newer or older version such as `v2` or `final`, or the same title and date) are shown beside the archived item, to file as a new version, keep both, or skip.
- **Questions:** when the same unknown term comes up again and again, Carrel asks you once, learns the answer in the archive's glossary, and drafts the waiting items again.
- **Review:** approve, hold in Holding, move, edit the card in your editor, or reject. Each approved batch is one change in history, so it can be undone.

## The interactive mode

Run `carrel` on its own for screens for Status, Review, Questions, Browse, History, Ingest and Settings. Press `i` to choose what to ingest with your file picker (yazi, lf, nnn, ranger, vifm or fzf) or the built-in one. Settings covers this device's picker, editor and model, and the archive's shared settings.

## Models

Every model runs on your computer, through **providers**, separate programs Carrel talks to:

| Provider | Gives Carrel | Where |
| --- | --- | --- |
| `carrel-provider-apple` | Apple's on-device model, PDF text (PDFKit), OCR (Vision) | Macs with Apple Intelligence |
| `carrel-provider-mlx` | Open models through MLX | Apple-silicon Macs |
| `carrel-provider-llama` | Open models through llama.cpp | macOS, Linux and Windows |
| `carrel-provider-extract` | PDF text, and OCR through Tesseract | macOS, Linux and Windows |

`carrel models` lists open models that are known to work, with their size, memory and license, and downloads one only when you ask, checked against a pinned checksum. The benchmark's results, in [`docs/bench/`](https://github.com/HannahARose/carrel/tree/main/docs/bench), say how each does; `carrel settings set model NAME` chooses one. Only `carrel-fetch`, the network helper, ever goes online, and it logs every request.

## Keeping the archive safe

- **Backups** with [Kopia](https://kopia.io): `carrel backup setup`, then a snapshot after every batch you approve.
- **History and undo** for every change Carrel makes, including settings.
- **Portable names:** files Carrel creates have names that work on macOS, Windows and Linux.
- **Restructure signals:** `carrel status` points out collections that are crowded, uncertain placements that gather in one place, and tags used across collections.

## Install

Download the archive for your platform below, unpack it, and put its programs together in a folder on your `PATH`. Each archive includes Kopia and every provider for its platform, with `THIRD-PARTY-LICENSES.md`. Checksums are in `SHA256SUMS`, and each archive has a build attestation (`gh attestation verify FILE --repo HannahARose/carrel`).

The [user guide](https://github.com/HannahARose/carrel/wiki/User-Guide) explains each part, and [Command-Line Tool](https://github.com/HannahARose/carrel/wiki/Command-Line-Tool) lists every command. Developers can start with [Architecture](https://github.com/HannahARose/carrel/wiki/Architecture).
