# The v0.5 gate

v0.5 ships when the owner can do everything from the Mac app that they do with the `carrel` command line and its interactive mode, and uses the app for a week instead of the interactive mode (issue #84, `docs/design/mac-app.md`). This is the checklist for that run, and the record of it. Like the gates before it, it's run with the others before 1.0 (#38).

It tests the app as an everyday interface: every capability in the [Interfaces](dev/interfaces.md) table's Mac app column, used on your real archive, plus the background agent that keeps working while the app is closed.

## Before

- [ ] **The app:** download the latest development build from CI (the **Mac app** job's `Carrel.app` artifact on `dev`), or build it with Xcode (`apple/CarrelApp/README.md`), and move it to Applications. It's signed ad hoc, so the first launch goes through System Settings → Privacy & Security → Open Anyway (`docs/guide/mac-app.md`).
- [ ] **The command line:** install the same version of `carrel` from `dev`, so the app and the command line agree.
- [ ] **Backups:** if they aren't set up yet, leave them for step 9 so the app sets them up.
- [ ] **Something to file:** a handful of new files and a folder from your Downloads, including a PDF, a photo, a zip and a duplicate of something already filed.
- [ ] **A project to check out** for the week, ideally a folder you'll work on, and a folder for the desk.

## The run

1. [ ] **Open your archive:** File → Open Archive…, and check Status: the counts, problems, Recent, and the agent's and the index's state. Check the icon in the Dock and the welcome window in light, dark and tinted modes.
2. [ ] **Add items:** drag the files onto the window, and the folder with File → Add to Archive… (⌘O). Status shows the worker drafting them.
3. [ ] **Review:**
   - approve, hold, move (with the collection picker) and reject, one at a time and as a selection;
   - expand the zip, or keep it compressed;
   - file the duplicate as a version, or keep both;
   - edit one proposal's card in the inspector and check its problems show beside the field.
4. [ ] **Questions:** answer a term and pick a collection for another; dismiss one.
5. [ ] **Correct and edit:** ⌘K on a filed item with a broad correction ("it's a picture of A, not B") and a narrow one ("it's from 2019"), and check the changes before saving. ⌘E to edit a card directly.
6. [ ] **Browse:**
   - the collection tree, the list and the grid of thumbnails;
   - previews in the inspector for a PDF, a photo, a 3D model and a folder;
   - a restricted item showing its card only until asked;
   - History and Related for an item, and Enter on a related item;
   - New Collection…, Rename… and Expand… on a filed zip, each undone afterwards from History.
7. [ ] **Search (⌘F):** ten items you remember, in your own words, with and without filters. The results match `carrel search`'s, the matched passages are highlighted, and typing never waits on the model.
8. [ ] **Work on something for the week:**
   - check out the project from Browse, with a due date, and add the folder to the desk;
   - quit the app and work on both normally over several days;
   - check the menu bar list shows them, and that work sessions appear as you work, without the app open;
   - in Active, approve, combine, edit or drop the entries, then return the project after its preview, and archive the desk folder.
9. [ ] **Backups:** set them up from the app if they weren't (the password goes into the keychain), snapshot now, verify, and restore an item into a new folder. The snapshot list shows without the drive.
10. [ ] **Settings:**
    - change a device setting and a shared one, and undo the shared one from History;
    - see the models with their sizes, the providers in use and the file types not read;
    - check the index's state, rebuild it, and (optionally) switch to another embedding model while searching;
    - turn the agent off and on.
11. [ ] **History:** undo a change, and check the confirmation says what undoing restores and what it doesn't.
12. [ ] **Every interface agrees:** after a few of the steps above, check the same result from `carrel` and the interactive mode (the filed items, the history, the entries, the search results). Nothing the app did should need fixing elsewhere.
13. [ ] **A week of use:** use the app instead of the interactive mode for a week of your normal filing and work, and keep a note of anything you had to go back to the command line or the interactive mode for.

## Passing

The gate passes when:

- every step above worked from the app, with nothing that needed the command line or the interactive mode, apart from deliberate checks in step 12;
- the agent noticed the week's work with the app closed, and the menu bar list kept up with it;
- the app, the command line and the interactive mode never disagreed about the archive;
- nothing was lost or misplaced, and every change could be undone or restored;
- and the owner is willing to use the app as their everyday interface on the Mac.

Anything that doesn't pass becomes an issue in the v0.5 milestone, fixed before the release, or moved to a later milestone if it can wait.
