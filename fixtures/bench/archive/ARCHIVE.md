# Bench archive

A test archive for Carrel's model benchmark: one person's household, work and research papers, with collections that sometimes overlap on purpose. Every document and person in it is invented.

## Conventions

Collection and file names are plain words. Dates in file names are written `YYYY-MM-DD`.
