# Bench archive

This folder is a Carrel archive: an ordinary folder you can read with Finder and any Markdown reader.

- Start at [ARCHIVE.md](ARCHIVE.md), which links every collection.
- Each **collection** is a folder with a `_collection.md` explaining what belongs in it.
- Each **item** has a **card** beside it: `Paper.pdf` is described by `Paper.pdf.md`.
- `Active/` shows what is checked out, `Journal/` logs work sessions, and `Holding/` has items waiting to be filed.
- `_System/` holds data for programs, including the format specification (`_System/FORMAT.md`).
